## 一、推荐展示案例

以下 5 个案例作为**优先推荐展示**，覆盖生命科学与生物制造核心知识点，文献丰富度高，演示效果稳定。

### 1. mRNA 疫苗递送技术（case-004）

| 项目 | 内容 |
|---|---|
| **案例 ID** | `case-004` |
| **标题** | mRNA 疫苗递送技术 |

**科研训练任务覆盖：**

- 疫苗平台快速响应机制

**推荐检索关键词：**
```
mRNA vaccine
lipid nanoparticle
pseudouridine

nucleoside modification
```

## 二、推荐检索关键词汇总

以下关键词在文献检索中**通常更容易返回相关文献**，建议在演示时优先使用：

| 案例 | 优先关键词（通常返回结果最多） |
|---|---|
| mRNA 疫苗 | `mRNA vaccine lipid nanoparticle` |
| CAR-T | `CAR-T therapy chimeric antigen receptor` |
| CRISPR | `CRISPR-Cas9 gene therapy` |
| 细胞凋亡 | `apoptosis BCL-2 inhibitor venetoclax` |
| PD-1/PD-L1 | `PD-1 immune checkpoint pembrolizumab` |

> **注意**：文献检索依赖外部服务（Semantic Scholar / CrossRef / PubMed），每次返回结果数量和顺序可能不同。建议使用上述关键词，通常更容易返回相关文献，但不能保证每次都有固定数量的结果。

## 三、预期页面表现

### 正常表现

1. **/cases 页面**
   - 显示 23 个产业案例卡片（后端正常时）
   - 前 6 个为精选案例，优先展示推荐案例
   - 支持搜索和筛选
   - 点击卡片可查看详情弹窗

2. **/research 页面**
   - 选择案例后生成 4 个科研训练任务
   - 每个任务卡支持"文献支撑"功能
   - 文献检索返回结果后可选择文献生成笔记

3. **文献支撑**
   - 支持 Semantic Scholar / CrossRef / PubMed 检索
   - 返回结果包含标题、作者、DOI 等基本信息
   - 选择文献后可生成文献支撑笔记

### 可能的非正常表现

| 现象 | 原因 | 严重程度 |
|---|---|---|
| 案例加载失败，显示"暂时加载不完整" | 后端未启动 | P0 |
| 文献检索返回 0 条结果 | 网络问题或关键词太冷门 | P1 |
| 科研任务生成慢 | AI 接口响应延迟 | P1 |
| 页面样式轻微错位 | 浏览器兼容性 | P2 |

## 五、演示风险提示

### 高风险

1. **后端未启动**：案例数据依赖后端 API，未启动时会显示 fallback 数据（仅 5 个 mock 案例）
2. **网络不稳定**：文献检索依赖外部服务，网络不佳时可能无法返回结果
3. **数据库未重置**：demo 数据库可能被修改过，演示前建议执行 `bash scripts/reset_demo_db.sh`

### 中风险

1. **文献结果数量不确定**：每次检索返回结果数量和顺序可能不同，取决于外部服务
2. **AI 生成任务时间**：科研任务生成依赖 AI 接口，响应时间可能在 3-10 秒之间

### 低风险

1. **浏览器兼容性**：部分 CSS 效果在旧版浏览器中可能不完美
2. **响应式布局**：极窄屏幕下部分布局可能轻微压缩

### 演示前检查清单

```bash
# 1. 检查后端是否启动
curl http://localhost:9090/api/health

# 2. 检查前端是否启动
curl http://localhost:3001/cases

# 3. 重置 demo 数据库（可选）
bash scripts/reset_demo_db.sh

# 4. 快速 smoke 测试
bash scripts/smoke_demo_api.sh
```
